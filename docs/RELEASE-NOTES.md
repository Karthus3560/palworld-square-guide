# Palbox Square Guide 1.0.0

Adds a fixed blue square inside your existing Palbox circle, aligned with the Palbox and using the original boundary materials. No UE4SS, Lua or trainer required.

**Install:** close the game, extract the ZIP and copy its `Pal` folder into your Palworld installation. Final location: `Pal/Content/Paks/~mods/PalboxSquareGuide_P.pak`.

**Tested:** Windows Steam v1.0.5.102999 (build 25246127), with user gameplay confirmation. Other versions and multiplayer combinations are not separately verified.

**Compatibility:** follows expansion mods that resize the visible boundary; does not change territory or repair Pal work/navigation issues. Other PAKs overriding the same Palbox blueprint may conflict.

**Uninstall:** close the game and remove the single PAK.
